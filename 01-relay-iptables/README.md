# 1. Труба: проброс порта

Российский сервер ничего не расшифровывает, а просто перекладывает пакеты на выход.

```
телефон ──TCP/UDP :443──► мост (DNAT) ──► выход :443
```

## Шаги

1. На выходе уже работает твоё подключение (VLESS Reality, Hysteria2 — любое) на порту 443.
2. На мосте: `EXIT_IP=<EXIT_IP> PORT=443 bash relay.sh`.
3. На телефоне в настройках подключения меняешь адрес `<EXIT_IP>` на `<BRIDGE_IP>`. Больше ничего не трогаешь.
4. Сохранить правила после перезагрузки: `apt install iptables-persistent && netfilter-persistent save`.

## Плюсы и минусы

- ✅ 10 минут, ноль настроек на телефоне, на мосте почти не тратится процессор.
- ❌ Российские сайты напрямую не отпустит: банк видит зарубежный айпи.
- ❌ На другой выход сам не переключится. Выход умер — умер весь обход.
- ❌ Маскировка та же, что у выхода. Её видно на участке мост → выход.

Если что-то из этого мешает — переходи на [цепочку 3X-UI](../02-chain-3x-ui).
