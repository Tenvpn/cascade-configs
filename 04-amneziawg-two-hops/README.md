# 4. AmneziaWG в два прыжка

Для тех, кто сидит на Амнезии. Между серверами туннель AmneziaWG (`awg0`): мост — клиент, выход — сервер.
На мосте своя точка Амнезии для телефонов (`awg1`), и весь её трафик заворачивается в `awg0`.

```
телефон ──AWG (awg1)──► мост ──AWG (awg0)──► выход ──► интернет
```

## Файлы

| Файл | Где |
|---|---|
| `exit-awg0.conf` | выход: сервер межсерверного туннеля |
| `bridge-awg0.conf` | мост: клиент туннеля к выходу (`Table = off` + таблица 100 только для трафика из awg1) |
| `bridge-awg1.conf` | мост: точка для телефонов |
| `phone.conf` | телефон |

## Шаги

1. На обоих серверах поставь AmneziaWG (пакет `amneziawg` / `amneziawg-tools` для своего дистрибутива).
2. Ключи: `awg genkey | tee priv | awg pubkey > pub`. Отдельная пара на каждый интерфейс и на каждый телефон.
3. Параметры обфускации `Jc, Jmin, Jmax, S1, S2, H1–H4` сгенерируй, например, приложением AmneziaVPN
   при создании сервера. Пара `exit-awg0` + `bridge-awg0` должна совпадать до символа, и пара
   `bridge-awg1` + `phone` тоже. Если у тебя AmneziaWG 2.0, добавь новые параметры из своего генератора
   в обе половины пары.
4. Подними интерфейсы по порядку: на выходе `awg-quick up awg0`, на мосте `awg-quick up awg0`, затем `awg-quick up awg1`.
   Автозапуск: `systemctl enable awg-quick@awg0 awg-quick@awg1`.
5. Проверка: на мосте `awg show` — у `awg0` должен быть свежий handshake. С телефона `ifconfig.me` показывает `<EXIT_IP>`.

## Важно

- **Между серверами — тоже Амнезия, не голый WireGuard.** Участок из России за границу проверяют так же, как телефон,
  а голый WireGuard видно по первому пакету.
- `Table = off` на мосте обязателен. Без него `awg-quick` заберёт весь трафик моста в туннель, включая твой SSH.
- Российские сайты напрямую здесь не идут: всё уходит на выход. Если нужно «банк напрямую», бери
  [цепочку Xray](../02-chain-3x-ui) или раскидывай `geoip:ru` через ipset (это отдельная история).
- Обновляй AmneziaWG на серверах и в приложениях: старые версии протокола ловят первыми.
