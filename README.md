# Каскадный ВПН: шесть схем и конфиги к ним

Конфиги к ролику «Каскадный ВПН: все виды и как собрать каждый» с YouTube-канала TENVPN.
По папке на каждый вид: что это, когда брать, файлы и шаги.

Каскад — это когда телефон подключается не к зарубежному серверу, а к российскому (**мост, вход**),
а тот пересылает трафик за границу (**выход**). Проверяющий видит соединение с российским хостингом,
а вход и выход живут на разных адресах.

```
телефон ──► мост в России ──► выход за границей ──► интернет
```

| # | Вид | Папка | Когда брать |
|---|---|---|---|
| 1 | Труба (проброс порта iptables) | [01-relay-iptables](01-relay-iptables) | себе одному, попробовать за 10 минут |
| 2 | Цепочка Xray на 3X-UI | [02-chain-3x-ui](02-chain-3x-ui) | семье, нужны банки и Госуслуги напрямую |
| 3 | Каскад по IPv6 | [03-ipv6](03-ipv6) | IPv4 выхода забанили, а сервер жалко |
| 4 | AmneziaWG в два прыжка | [04-amneziawg-two-hops](04-amneziawg-two-hops) | сидишь на Амнезии |
| 5 | Вход через CDN (XHTTP) | [05-cdn-entry](05-cdn-entry) | мобильный интернет в белых списках |
| 6 | Два на два с балансиром | [06-balancer-2x2](06-balancer-2x2) | не чинить каждый вечер, 3X-UI или Remnawave |

## Обозначения в файлах

Всё в угловых скобках заменить своим:

| Метка | Что это |
|---|---|
| `<EXIT_IP>` / `<EXIT_IPV6>` | IPv4 / IPv6 зарубежного сервера |
| `<BRIDGE_IP>` | IPv4 российского моста |
| `<YOUR_DOMAIN>` | свой домен (купить за пару сотен в год) |
| `<UUID_BRIDGE>` | UUID, по которому мост ходит на выход (`xray uuid`) |
| `<UUID_PHONE>` | UUID для телефона (свой на каждое устройство) |
| `<EXIT_REALITY_PRIVATE_KEY>` / `<EXIT_REALITY_PUBLIC_KEY>` | пара ключей Reality выхода (`xray x25519`) |
| `<BRIDGE_REALITY_PRIVATE_KEY>` / `<BRIDGE_REALITY_PUBLIC_KEY>` | пара ключей Reality моста |
| `<SHORT_ID>` | 8–16 hex-символов (`openssl rand -hex 8`) |
| `<EXIT_1_IP>` / `<EXIT_2_IP>`, `<EXIT_1_REALITY_PUBLIC_KEY>` / `<EXIT_2_REALITY_PUBLIC_KEY>` | адреса и ключи двух выходов в схеме 6 |
| `<SECRET_PATH>` | длинный случайный путь для XHTTP в схеме 5 (`openssl rand -hex 16`) |
| `<..._AWG_...>`, `<JC>`…`<H4>` | ключи, порты и параметры обфускации AmneziaWG в схеме 4 (см. её README) |

JSON-файлы — фрагменты под 3X-UI («Настройки Xray» → «Исходящие» / «Маршрутизация») или
полные конфиги под голый Xray (`*-full.json`). Полный конфиг перед запуском проверяй:
`xray run -test -c config.json`.

## Пять правил, на которых все сыпятся

1. **Маскировка только под свой домен (selfsteal).** Чужой SNI (max.ru, apple.com, microsoft) с ноября
   запрещают сами российские хостеры: сервер останавливают. Во всех конфигах тут Reality смотрит на
   твой собственный сайт на том же сервере: `target: 127.0.0.1:8443`, а на 8443 Caddy или nginx отдают
   `<YOUR_DOMAIN>` с настоящим сертификатом.
2. **Отпечаток (fingerprint) — `firefox`**, не `chrome`: его режут чаще всего.
3. **Вход проверяй загрузкой, а не пингом.** Скачай файл хотя бы на 1 МБ через мост. Бывает, что соединение
   из одних дата-центров замерзает ровно на 16 КБ, а из других идёт на полной скорости.
4. **Входов два, в разных дата-центрах.** Операторы режут по-разному: мост, живой на МТС, на Т2 может молчать.
5. **У выхода должен быть IPv6.** Тогда при бане IPv4 переходишь на схему 3 одной правкой.

## Не хочешь собирать сам

Мы держим так [TENVPN](https://tenproxy.site/app/): несколько входов в России, выходы в нескольких странах,
IPv6 между ними и отдельные входы под белые списки. Приложение для Android само выбирает быстрый сервер по пингу.
